AxTraxNG to Qumulex Converter

Turns an AxTraxNG user export into a file the Qumulex People > Import Cardholders tool accepts. Every person ends up on one row, with all of their cards in SiteCode-CardCode form, separated by spaces.

Runs in your browser. The file is never uploaded.

STEP 1Load the AxTraxNG export

In AxTraxNG: Tools > Import/Export Data > Export Users properties, Excel format. Drop that file here (.xls, .xlsx or .csv).

STEP 2Match Access Groups to Qumulex Groups

Create the Groups in Qumulex first. Open each Group and copy the ID at the end of the browser's address bar into the matching row. To put an Access Group's people into more than one Qumulex Group, enter several GroupIDs separated by a space. Leave it blank to import people without a Group. Untick a row to leave those people out.

STEP 4Save the files

Set your Scope to the Customer level, then import the trial file and test those cards at a reader. When they work, import the remaining file. The two files never share a person, so nobody is imported twice.

Don't import the Full Converted File to Qumulex if you import the trial as suggested. The trial people's cards will already exist in Qumulex, and the import will fail with a uniqueness error.
